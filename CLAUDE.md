## What this package does

epiextractr is an R package for downloading and loading EPI (Economic Policy Institute) Current Population Survey microdata extracts from https://microdata.epi.org. It reads `.feather` (Apache Arrow) files and returns tibbles with labeled variables.

There are no unit tests in this package. The `tests/` directory does not exist.

## Package architecture

Four source files in `R/`:

- **load_data.R** — Core functionality. `load_cps()` reads per-year `.feather` files from a local directory, selects columns via tidy evaluation (`...` forwarded to `dplyr::select`), and row-binds years together. Convenience wrappers `load_org()`, `load_basic()`, `load_may()`, `load_org_sample()` set the sample name. The extracts directory can be passed as `.extracts_dir` or set via environment variables (`EPIEXTRACTS_CPSORG_DIR`, `EPIEXTRACTS_CPSBASIC_DIR`, `EPIEXTRACTS_CPSMAY_DIR`).

- **download_data.R** — `download_cps()` downloads `.tar.gz` archives from microdata.epi.org and extracts them locally.

- **metadata.R** — `cps_version()` and `cps_citation()` read version/citation attributes stored on loaded data. `assert_cps_version()` validates a specific version.

- **checks.R** — Internal validation helpers: `valid_sample_name()` and `assert_valid_extract()`.

## Key conventions

- Documentation is roxygen2-based (do not edit `man/*.Rd` or `NAMESPACE` by hand).
- The `README.md` is generated from `README.Rmd` — edit the `.Rmd` source.
- Sample/demo data lives in `inst/extdata/` as `.feather` files, generated by `data-raw/sample_data.R`.
- CI via GitHub Actions (`.github/workflows/pkgdown.yaml`) builds the pkgdown site on push to master.
